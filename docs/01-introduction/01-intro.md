# Introduction to Postgres — 课程介绍

## 课程定位

本课程由数据库教育者、软件开发者 **Aaron Francis** 主讲，目标是以轻松、有趣的方式讲解 PostgreSQL，同时保证内容具有实际价值，并尊重学习者的时间。

课程重点是学习 **PostgreSQL 本身**，而不是某个平台的专属用法。课程由 Supabase 赞助并免费向社区开放；按照讲师的介绍，Supabase 希望这套课程教授真正的 Postgres。

## 学习内容

课程将围绕 PostgreSQL 的日常使用与设计展开，主要包括：

- **表设计**：如何创建结构合理的数据库表。
- **SQL 查询**：如何编写有效的查询。
- **索引**：理解并使用索引。
- **JSON**：学习 PostgreSQL 对 JSON 数据的处理能力。

## 学习方式与课程期望

课程会结合屏幕演示和手绘讲解。讲师希望学习者不仅掌握相关知识，也能减少对数据库的陌生感，甚至培养对数据库的兴趣。

讲师也鼓励学习者对课程提出反馈，以便持续改进教学内容。

------

**本节要点：** 这是一个免费、以 PostgreSQL 核心能力为重点的入门课程。后续学习将从表设计、查询、索引和 JSON 等主题展开。
